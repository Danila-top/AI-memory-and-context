# Context architecture

## Layers

1. **Working context** — the current task and immediate evidence.
2. **Project context** — durable facts, decisions, specifications, and maps.
3. **Archive** — large historical material retained for retrieval rather than injected wholesale.
4. **External context** — repositories, files, databases, and tools.
5. **Provenance** — where each durable fact came from and when it was last checked.

## Design rule

Retrieval should be selective and source-aware; more context is not automatically better context.
