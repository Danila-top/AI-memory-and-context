# Retrieval policy

A memory system should retrieve information because it is relevant to the current task, not merely because it is recent or large.

## Ranking signals

1. direct semantic relevance;
2. task and project scope;
3. source reliability;
4. temporal validity;
5. explicit dependency on the current artifact.

## Conflict handling

When two memories disagree, preserve both source records, surface the conflict, and prefer explicit current evidence over silent overwriting.
